# 🚗 Smart Parking Management System

Smart Parking Management System is a web-based application developed using Flask, HTML, CSS, JavaScript, and PostgreSQL. This system helps in managing vehicle parking efficiently by tracking entry and exit details and calculating parking charges automatically.

## 🔹 Features
- Vehicle Entry & Exit Management
- Real-time Parking Status (Parked / Left)
- Automatic Charge Calculation
- Search Vehicle by Number
- User-friendly and Responsive UI

## 🔹 Technologies Used
- Backend: Python (Flask)
- Frontend: HTML, CSS, JavaScript
- Database: PostgreSQL
